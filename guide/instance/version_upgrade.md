# 实例版本升级

5.x 实例支持升级至当前服务提供的新版本，升级后不支持回退到历史版本。

## 升级前准备

- 建议客户端开启消费重试并保证消费幂等，避免升级期间短暂连接闪断或少量消息重复带来影响。

## 升级影响

- 升级过程中节点会分批滚动更新并切换主从；切换前虽会设置只读并同步主从进度，受主从切换及位点同步影响，仍可能出现少量消息重复投递以及分区顺序消息乱序
- 升级期间客户端连接和消息收发可能出现短暂闪断。
